# 神经网络的基本结构

## 神经元

神经元是神经网络的基本单元，它模拟了生物神经元的功能。

### 生物神经元

生物神经元是神经系统的基本单元，负责传递和处理信息。

#### 结构组成

- **细胞体**
  - 包含细胞核
  - 处理信息
  - 产生输出

- **树突**
  - 接收来自其他神经元的信号
  - 增加接收面积
  - 传递信号到细胞体

- **轴突**
  - 传递信号到其他神经元
  - 长的突起
  - 终端有突触

- **突触**
  - 神经元之间的连接
  - 传递化学信号
  - 可以增强或减弱

#### 工作原理

1. **接收信号**：树突接收来自其他神经元的信号
2. **整合信号**：细胞体整合所有接收到的信号
3. **产生输出**：如果信号超过阈值，产生输出信号
4. **传递信号**：通过轴突将信号传递给其他神经元

### 人工神经元

人工神经元是对生物神经元的数学抽象。

#### 基本结构

- **输入**
  - x₁, x₂, ..., xₙ
  - 来自其他神经元的信号

- **权重**
  - w₁, w₂, ..., wₙ
  - 每个输入的重要性

- **偏置**
  - b
  - 调整激活阈值

- **激活函数**
  - f(z)
  - 决定神经元的输出

#### 计算过程

1. **加权和**
   ```
   z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
   ```

2. **激活**
   ```
   y = f(z)
   ```

3. **输出**
   - y是神经元的输出
   - 传递给下一层神经元

## 网络结构

神经网络由多个神经元组成，形成层次化的结构。

### 输入层

输入层接收原始数据。

#### 特点

- **节点数**
  - 等于输入特征的维度
  - 不进行计算
  - 只传递数据

- **作用**
  - 接收原始输入
  - 传递到隐藏层
  - 不改变数据

### 隐藏层

隐藏层是神经网络的核心，负责处理和转换数据。

#### 单隐藏层

- **结构**
  - 一个隐藏层
  - 可以拟合任何连续函数
  - 适用于简单问题

- **容量**
  - 隐藏层节点数决定容量
  - 节点越多，表达能力越强
  - 但也容易过拟合

#### 多隐藏层

- **深度网络**
  - 多个隐藏层
  - 逐层提取特征
  - 表达能力更强

- **层次化特征**
  - 浅层学习简单特征
  - 深层学习复杂特征
  - 逐步抽象

#### 网络深度

- **浅层网络**
  - 1-2个隐藏层
  - 计算效率高
  - 适用于简单问题

- **深层网络**
  - 多个隐藏层
  - 表达能力强
  - 适用于复杂问题

### 输出层

输出层产生最终结果。

#### 分类任务

- **二分类**
  - 1个输出节点
  - 使用Sigmoid激活函数
  - 输出概率

- **多分类**
  - 多个输出节点
  - 使用Softmax激活函数
  - 输出每个类别的概率

#### 回归任务

- **单变量回归**
  - 1个输出节点
  - 使用线性激活函数
  - 输出连续值

- **多变量回归**
  - 多个输出节点
  - 使用线性激活函数
  - 输出多个连续值

## 前向传播

前向传播是指数据从输入层经过隐藏层传递到输出层的过程。

### 计算过程

#### 单层计算

对于第l层：

1. **线性变换**
   ```
   z^l = W^l * a^(l-1) + b^l
   ```
   其中：
   - W^l：第l层的权重矩阵
   - a^(l-1)：第l-1层的激活值
   - b^l：第l层的偏置
   - z^l：第l层的加权和

2. **非线性激活**
   ```
   a^l = f(z^l)
   ```
   其中：
   - f：激活函数
   - a^l：第l层的激活值

#### 整体过程

1. **输入层**
   ```
   a^0 = x
   ```

2. **隐藏层**
   ```
   z^1 = W^1 * a^0 + b^1
   a^1 = f(z^1)
   
   z^2 = W^2 * a^1 + b^2
   a^2 = f(z^2)
   
   ...
   ```

3. **输出层**
   ```
   z^L = W^L * a^(L-1) + b^L
   a^L = f(z^L)
   ```

4. **最终输出**
   ```
   y_pred = a^L
   ```

### 矩阵运算

#### 批量处理

为了提高计算效率，通常使用批量处理。

- **输入矩阵**
  ```
  X ∈ R^(m × n)
  ```
  其中：
  - m：批量大小
  - n：输入特征数

- **权重矩阵**
  ```
  W ∈ R^(n × h)
  ```
  其中：
  - n：输入特征数
  - h：隐藏层节点数

- **输出矩阵**
  ```
  Z ∈ R^(m × h)
  ```

#### 计算公式

```
Z = XW + b
A = f(Z)
```

## 反向传播

反向传播是指通过计算损失函数的梯度，从输出层向输入层传递误差，更新网络参数的过程。

### 损失函数

损失函数衡量模型预测与实际值之间的差异。

#### 回归损失

- **均方误差（MSE）**
  ```
  L = (1/2m) * Σ(y_pred - y_true)²
  ```

- **平均绝对误差（MAE）**
  ```
  L = (1/m) * Σ|y_pred - y_true|
  ```

#### 分类损失

- **交叉熵损失（二分类）**
  ```
  L = -[y*log(y_pred) + (1-y)*log(1-y_pred)]
  ```

- **交叉熵损失（多分类）**
  ```
  L = -Σy*log(y_pred)
  ```

### 梯度计算

#### 链式法则

使用链式法则计算梯度：

```
∂L/∂W^l = ∂L/∂a^l * ∂a^l/∂z^l * ∂z^l/∂W^l
```

#### 输出层梯度

对于输出层：

1. **损失对输出的梯度**
   ```
   ∂L/∂a^L
   ```

2. **输出对加权和的梯度**
   ```
   ∂a^L/∂z^L = f'(z^L)
   ```

3. **加和对权重的梯度**
   ```
   ∂z^L/∂W^L = a^(L-1)
   ```

4. **权重梯度**
   ```
   ∂L/∂W^L = ∂L/∂a^L * f'(z^L) * a^(L-1)
   ```

#### 隐藏层梯度

对于隐藏层l：

1. **从下一层传递的误差**
   ```
   δ^(l+1) = ∂L/∂z^(l+1)
   ```

2. **当前层的误差**
   ```
   δ^l = (W^(l+1))^T * δ^(l+1) * f'(z^l)
   ```

3. **权重梯度**
   ```
   ∂L/∂W^l = δ^l * (a^(l-1))^T
   ```

### 参数更新

#### 梯度下降

使用梯度下降更新参数：

```
W^l = W^l - η * ∂L/∂W^l
b^l = b^l - η * ∂L/∂b^l
```

其中：
- η：学习率

#### 随机梯度下降（SGD）

使用单个样本计算梯度：

```
W^l = W^l - η * ∂L_i/∂W^l
b^l = b^l - η * ∂L_i/∂b^l
```

其中：
- ∂L_i/∂W^l：第i个样本的梯度

#### 小批量梯度下降

使用一小批样本计算梯度：

```
W^l = W^l - η * (1/m) * Σ∂L_i/∂W^l
b^l = b^l - η * (1/m) * Σ∂L_i/∂b^l
```

其中：
- m：批量大小

## 激活函数

激活函数引入非线性，使神经网络能够学习复杂的模式。

### Sigmoid

#### 公式

```
σ(z) = 1 / (1 + e^(-z))
```

#### 特点

- **输出范围**：(0, 1)
- **单调性**：单调递增
- **可微性**：处处可微

#### 优点

- 输出在(0,1)之间，可以表示概率
- 平滑的梯度
- 适合二分类输出

#### 缺点

- 梯度消失问题
- 输出不以0为中心
- 计算较慢（指数运算）

### Tanh

#### 公式

```
tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))
```

#### 特点

- **输出范围**：(-1, 1)
- **单调性**：单调递增
- **奇函数**：tanh(-z) = -tanh(z)

#### 优点

- 输出以0为中心
- 梯度比Sigmoid更陡
- 适合隐藏层

#### 缺点

- 仍然存在梯度消失问题
- 计算较慢（指数运算）

### ReLU

#### 公式

```
ReLU(z) = max(0, z)
```

#### 特点

- **输出范围**：[0, +∞)
- **分段线性**
- **计算简单**

#### 优点

- 解决梯度消失问题
- 计算效率高
- 收敛速度快

#### 缺点

- Dead ReLU问题（神经元死亡）
- 输出不以0为中心

### Leaky ReLU

#### 公式

```
LeakyReLU(z) = max(αz, z)
```

其中：
- α：小的正数（如0.01）

#### 特点

- 解决Dead ReLU问题
- 在负区间有小的梯度

#### 优点

- 解决Dead ReLU问题
- 计算效率高

#### 缺点

- 需要调整α参数

### Softmax

#### 公式

```
softmax(z_i) = e^(z_i) / Σ(e^(z_j))
```

#### 特点

- **输出范围**：(0, 1)
- **输出和为1**：Σsoftmax(z_i) = 1
- **用于多分类**

#### 优点

- 输出可以解释为概率
- 可微

#### 缺点

- 计算较慢（指数运算）

## 网络架构

### 全连接网络

所有神经元之间都有连接。

#### 特点

- **连接方式**
  - 每个神经元与上一层的所有神经元连接
  - 权重矩阵是稠密的

- **参数数量**
  - 参数数量 = 输入维度 × 输出维度 + 输出维度
  - 参数数量可能很大

#### 应用

- 适用于结构化数据
- 适用于小规模图像
- 适用于简单任务

### 卷积网络

使用卷积操作，适合处理网格数据。

#### 特点

- **局部连接**
  - 神经元只连接局部区域
  - 保留空间信息

- **参数共享**
  - 相同的权重用于不同位置
  - 减少参数数量

#### 应用

- 图像分类
- 目标检测
- 图像分割

### 循环网络

具有循环连接，适合处理序列数据。

#### 特点

- **循环连接**
  - 神经元连接到自身
  - 保留历史信息

- **时序建模**
  - 处理变长序列
  - 捕捉时序依赖

#### 应用

- 自然语言处理
- 时间序列预测
- 语音识别

### Transformer

基于自注意力机制，适合处理序列数据。

#### 特点

- **自注意力**
  - 捕捉序列中不同位置的依赖
  - 不依赖距离

- **并行计算**
  - 可以并行处理序列
  - 训练效率高

#### 应用

- 机器翻译
- 文本生成
- 问答系统

## 网络训练

### 训练过程

1. **初始化**
   - 初始化权重和偏置
   - 通常使用随机初始化

2. **前向传播**
   - 输入数据通过网络
   - 计算预测输出

3. **计算损失**
   - 计算预测与真实值的差异
   - 使用损失函数

4. **反向传播**
   - 计算损失对参数的梯度
   - 从输出层到输入层

5. **参数更新**
   - 使用梯度更新参数
   - 使用优化算法

6. **重复**
   - 重复步骤2-5
   - 直到收敛

### 训练技巧

#### 权重初始化

- **随机初始化**
  - 随机初始化权重
  - 打破对称性

- **Xavier初始化**
  - 适用于Sigmoid和Tanh
  - 保持方差稳定

- **He初始化**
  - 适用于ReLU
  - 保持方差稳定

#### 批量归一化

- **作用**
  - 加速训练
  - 稳定梯度
  - 允许更大的学习率

- **方法**
  - 对每层的输入进行归一化
  - 使用可学习的缩放和平移

#### Dropout

- **作用**
  - 防止过拟合
  - 提高泛化能力

- **方法**
  - 训练时随机丢弃神经元
  - 测试时使用所有神经元

#### 学习率调度

- **作用**
  - 加速收敛
  - 提高最终性能

- **方法**
  - 学习率衰减
  - 余弦退火
  - 循环学习率
