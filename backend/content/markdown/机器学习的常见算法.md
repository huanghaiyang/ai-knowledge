# 机器学习的常见算法

## 线性模型

线性模型是最简单但最有效的机器学习算法之一。

### 线性回归

线性回归用于回归问题，假设输入和输出之间存在线性关系。

#### 简单线性回归

简单线性回归只有一个输入特征。

- **模型公式**
  ```
  y = wx + b
  ```
  其中：
  - y：预测值
  - w：权重
  - x：输入特征
  - b：偏置

- **损失函数**
  ```
  J(w, b) = (1/2m) * Σ(y_pred - y_true)²
  ```
  其中：
  - m：样本数量
  - y_pred：预测值
  - y_true：真实值

- **优化方法**
  - 最小二乘法
  - 梯度下降

#### 多元线性回归

多元线性回归有多个输入特征。

- **模型公式**
  ```
  y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
  ```

- **矩阵形式**
  ```
  y = Xw + b
  ```

#### 正则化线性回归

- **岭回归（Ridge）**
  - 添加L2正则化
  - 防止过拟合
  - 适用于高维数据

- **LASSO回归**
  - 添加L1正则化
  - 产生稀疏解
  - 用于特征选择

### 逻辑回归

逻辑回归用于分类问题，尽管名字中有"回归"。

#### 二分类逻辑回归

- **Sigmoid函数**
  ```
  σ(z) = 1 / (1 + e^(-z))
  ```

- **模型公式**
  ```
  P(y=1|x) = σ(wx + b)
  ```

- **损失函数**
  - 交叉熵损失
  ```
  J(w, b) = -[y*log(y_pred) + (1-y)*log(1-y_pred)]
  ```

#### 多分类逻辑回归

- **Softmax函数**
  ```
  softmax(z_i) = e^(z_i) / Σ(e^(z_j))
  ```

- **模型公式**
  ```
  P(y=i|x) = softmax(Wx + b)_i
  ```

## 树模型

树模型基于树结构进行决策，易于理解和解释。

### 决策树

决策树通过一系列的规则进行决策。

#### 树的构建

- **选择最优特征**
  - 信息增益
  - 基尼指数
  - 卡方检验

- **选择最优切分点**
  - 穷举搜索
  - 离散化连续特征

- **停止条件**
  - 所有样本属于同一类别
  - 没有更多特征
  - 达到最大深度
  - 样本数量过少

#### 决策树的优缺点

- **优点**
  - 易于理解和解释
  - 不需要特征缩放
  - 可以处理数值和类别特征
  - 可以处理缺失值

- **缺点**
  - 容易过拟合
  - 不稳定（数据小变化可能导致大变化）
  - 可能偏向于特征值多的特征

### 随机森林

随机森林是由多个决策树组成的集成算法。

#### 集成方法

- **Bagging（Bootstrap Aggregating）**
  - 有放回抽样
  - 训练多个决策树
  - 投票或平均

- **特征随机选择**
  - 每个节点只考虑部分特征
  - 增加多样性
  - 减少相关性

#### 随机森林的优缺点

- **优点**
  - 不容易过拟合
  - 性能优于单个决策树
  - 可以评估特征重要性
  - 可以处理高维数据

- **缺点**
  - 模型复杂
  - 训练时间长
  - 难以解释
  - 占用内存大

### 梯度提升树

梯度提升树通过梯度提升方法构建的集成算法。

#### 梯度提升

- **基本思想**
  - 逐步添加树
  - 每棵树拟合前一棵树的残差
  - 最小化损失函数

- **算法步骤**
  1. 初始化模型
  2. 计算负梯度
  3. 拟合残差
  4. 更新模型
  5. 重复步骤2-4

#### XGBoost

XGBoost是高效的梯度提升树实现。

- **特点**
  - 正则化
  - 并行处理
  - 缺失值处理
  - 稀疏感知

- **优化**
  - 二阶近似
  - 列块存储
  - 缓存感知访问

## 支持向量机

支持向量机（SVM）是用于分类和回归的监督学习算法。

### 线性SVM

线性SVM在特征空间中找到最优超平面。

#### 超平面

- **公式**
  ```
  w·x + b = 0
  ```

- **间隔**
  - 函数间隔
  - 几何间隔

#### 优化目标

- **原始问题**
  ```
  min (1/2)||w||²
  s.t. y_i(w·x_i + b) ≥ 1
  ```

- **对偶问题**
  ```
  max Σα_i - (1/2)ΣΣα_iα_jy_iy_j(x_i·x_j)
  s.t. 0 ≤ α_i ≤ C, Σα_iy_i = 0
  ```

### 核技巧

核技巧将线性模型扩展到非线性问题。

#### 核函数

- **线性核**
  ```
  K(x, x') = x·x'
  ```

- **多项式核**
  ```
  K(x, x') = (x·x' + c)^d
  ```

- **RBF核（高斯核）**
  ```
  K(x, x') = exp(-γ||x - x'||²)
  ```

- **Sigmoid核**
  ```
  K(x, x') = tanh(αx·x' + c)
  ```

#### 核技巧的作用

- **隐式映射**
  - 将数据映射到高维空间
  - 不需要显式计算映射

- **非线性分类**
  - 在高维空间中线性可分
  - 解决非线性问题

## 神经网络

神经网络是模拟人脑结构的机器学习算法。

### 前馈神经网络

前馈神经网络是最基本的神经网络结构。

#### 网络结构

- **输入层**
  - 接收输入数据
  - 节点数等于输入特征数

- **隐藏层**
  - 处理和转换数据
  - 可以有多层
  - 节点数可调

- **输出层**
  - 产生最终结果
  - 节点数取决于任务

#### 前向传播

- **公式**
  ```
  z = Wx + b
  a = σ(z)
  ```
  其中：
  - z：加权和
  - a：激活值
  - σ：激活函数

- **常见激活函数**
  - Sigmoid
  - Tanh
  - ReLU
  - Leaky ReLU

#### 反向传播

- **链式法则**
  ```
  ∂L/∂w = ∂L/∂a * ∂a/∂z * ∂z/∂w
  ```

- **梯度下降**
  ```
  w = w - η * ∂L/∂w
  ```

### 卷积神经网络（CNN）

CNN主要用于处理图像等网格数据。

#### 卷积层

- **卷积操作**
  ```
  (I * K)(i, j) = ΣΣ I(i+m, j+n)K(m, n)
  ```

- **参数共享**
  - 减少参数数量
  - 提高计算效率

- **局部连接**
  - 捕捉局部特征
  - 保留空间信息

#### 池化层

- **最大池化**
  ```
  max_{m,n} I(i+m, j+n)
  ```

- **平均池化**
  ```
  avg_{m,n} I(i+m, j+n)
  ```

- **作用**
  - 降低数据维度
  - 减少计算量
  - 增加不变性

#### 全连接层

- **作用**
  - 分类或回归
  - 整合特征
  - 产生输出

### 循环神经网络（RNN）

RNN主要用于处理序列数据。

#### 循环结构

- **公式**
  ```
  h_t = σ(W_hh * h_{t-1} + W_xh * x_t + b)
  y_t = σ(W_hy * h_t + c)
  ```

- **特点**
  - 保留序列信息
  - 共享参数
  - 处理变长序列

#### LSTM

LSTM（长短期记忆网络）解决长序列依赖问题。

- **门控机制**
  - 遗忘门
  - 输入门
  - 输出门

- **细胞状态**
  - 长期记忆
  - 梯度流动
  - 解决梯度消失

#### GRU

GRU（门控循环单元）是LSTM的简化版本。

- **门控机制**
  - 更新门
  - 重置门

- **特点**
  - 参数更少
  - 训练更快
  - 性能相近

### Transformer

Transformer基于自注意力机制，主要用于自然语言处理。

#### 自注意力

- **公式**
  ```
  Attention(Q, K, V) = softmax(QK^T / √d_k)V
  ```

- **多头注意力**
  - 多个注意力头
  - 捕捉不同关系
  - 提高表达能力

#### 位置编码

- **正弦位置编码**
  ```
  PE_{pos, 2i} = sin(pos / 10000^(2i/d))
  PE_{pos, 2i+1} = cos(pos / 10000^(2i/d))
  ```

- **可学习位置编码**
  - 作为可学习参数
  - 端到端学习

## 聚类算法

聚类算法将相似的数据点分组。

### K-means

K-means是基于距离的聚类算法。

#### 算法步骤

1. 随机选择K个中心点
2. 将每个数据点分配到最近的中心点
3. 重新计算每个簇的中心点
4. 重复步骤2和3直到收敛

#### 优缺点

- **优点**
  - 简单易实现
  - 计算效率高
  - 适用于大规模数据

- **缺点**
  - 需要预先指定K值
  - 对初始中心点敏感
  - 假设簇是球形的

### 层次聚类

层次聚类是基于层次结构的聚类算法。

#### 凝聚式聚类

- **算法步骤**
  1. 每个数据点作为一个簇
  2. 合并最近的两个簇
  3. 重复步骤2直到只有一个簇

- ** linkage方法**
  - Single linkage
  - Complete linkage
  - Average linkage
  - Ward linkage

#### 分裂式聚类

- **算法步骤**
  1. 所有数据点作为一个簇
  2. 分裂一个簇
  3. 重复步骤2直到每个数据点一个簇

### DBSCAN

DBSCAN是基于密度的聚类算法。

#### 算法原理

- **核心点**
  - 在半径ε内有至少MinPts个点

- **边界点**
  - 在核心点的半径ε内
  - 不是核心点

- **噪声点**
  - 既不是核心点也不是边界点

#### 优缺点

- **优点**
  - 不需要预先指定簇的数量
  - 可以发现任意形状的簇
  - 能够识别噪声点

- **缺点**
  - 对参数敏感
  - 难以处理不同密度的簇
  - 对高维数据效果不佳

## 其他算法

### 朴素贝叶斯

朴素贝叶斯基于贝叶斯定理和特征独立性假设。

#### 贝叶斯定理

```
P(y|x) = P(x|y)P(y) / P(x)
```

#### 朴素假设

```
P(x|y) = P(x₁|y)P(x₂|y)...P(xₙ|y)
```

#### 优缺点

- **优点**
  - 简单快速
  - 适用于高维数据
  - 对缺失值不敏感

- **缺点**
  - 特征独立性假设太强
  - 对相关特征敏感

### K近邻（KNN）

KNN是基于实例的学习算法。

#### 算法步骤

1. 计算测试样本与所有训练样本的距离
2. 选择距离最近的K个样本
3. 根据K个样本的标签进行预测

#### 距离度量

- **欧氏距离**
  ```
  d(x, y) = √(Σ(x_i - y_i)²)
  ```

- **曼哈顿距离**
  ```
  d(x, y) = Σ|x_i - y_i|
  ```

- **余弦相似度**
  ```
  cos(x, y) = (x·y) / (||x|| * ||y||)
  ```

#### 优缺点

- **优点**
  - 简单易理解
  - 无需训练
  - 适用于多分类

- **缺点**
  - 计算复杂度高
  - 对异常值敏感
  - 需要选择合适的K值

### 降维算法

#### PCA（主成分分析）

- **原理**
  - 找到数据的主成分
  - 保留最重要的成分
  - 丢弃不重要的成分

- **步骤**
  1. 标准化数据
  2. 计算协方差矩阵
  3. 计算特征值和特征向量
  4. 选择前k个特征向量
  5. 投影数据

#### t-SNE

- **原理**
  - 保持数据点之间的局部关系
  - 将高维数据映射到低维空间
  - 适用于可视化

#### LDA（线性判别分析）

- **原理**
  - 最大化类间距离
  - 最小化类内距离
  - 有监督降维

## 算法选择指南

### 根据数据量选择

- **小数据集**
  - 简单模型
  - 正则化
  - 交叉验证

- **大数据集**
  - 深度学习
  - 集成方法
  - 在线学习

### 根据数据类型选择

- **结构化数据**
  - 线性模型
  - 树模型
  - 集成方法

- **非结构化数据**
  - 深度学习
  - CNN
  - RNN

### 根据问题类型选择

- **分类问题**
  - 逻辑回归
  - SVM
  - 决策树
  - 神经网络

- **回归问题**
  - 线性回归
  - 决策树回归
  - 神经网络回归

- **聚类问题**
  - K-means
  - 层次聚类
  - DBSCAN

### 根据可解释性选择

- **需要可解释性**
  - 线性模型
  - 决策树
  - 规则模型

- **不需要可解释性**
  - 神经网络
  - 集成方法
  - 深度学习
